# 用户心理与留存护城河商业计划（18–28 职业工作台）
> 2026-08-11 ｜ 上位：v3 功能线总纲。本文件把**使用/留存/依赖心理学**落到定位、功能线与可执行计划。
> 依据：Nir Eyal《Hooked》四步回路（Amplitude/Nir&Far）、James Clear《Atomic Habits》身份型习惯、endowed progress（Nunes & Drèze）、IKEA effect（Norton et al.）、损失厌恶（Kahneman & Tversky）、自我决定理论 SDT（Deci & Ryan）、感知理解/个性化信任研究。

## 0. 定位（心理版）
我们卖的不是功能，是三样心理资产：
1. **带不走的职业资本**（数据重力）— 理性锁定。
2. **一路陪跑的工作台**（工作流整合）— 行为锁定。
3. **“你懂我”的认同**（身份+感知理解）— 情感锁定。
三层叠加 = 强工具依赖。理性上换不起、行为上换不动、情感上不想换。

## 1. 惯性 vs 第一步依赖：两者都要，分阶段侧重
| 阶段 | 心理目标 | 主打机制 | 产品落点 |
|---|---|---|---|
| 第 1 次（0–1 分钟） | 即时依赖/aha | endowed progress + 感知理解 | 导入培养方案立即解析出“你的”技能/路线，且预置已完成进度 |
| 前 2 周 | 习惯回路建立 | Hooked 四步 + 小胜投票 | 每日/每周“下一步”触发 + 记录证据=为身份投票 |
| 长期 | 惯性+锁定 | investment/data gravity + identity | 账本累积、阶段交接、身份陈述 |

## 2. 心理机制 → 功能映射（核心）
| 心理机制 | 原理 | 产品功能落点 |
|---|---|---|
| 内部触发 | 让产品成为某个情绪/问题的自动答案 | 拥有“我下一步该干嘛？”焦虑 → 工作台首页“现在最值得做”；求职期“我简历够吗？”→ 资本 hub 缺口提示 |
| 行动极简 | 降低 trigger→reward 摩擦 | 一键导入解析；“下一步”单按钮；移动端 dock |
| 可变奖励 | 猎奇/自我/社交三类 | 自我：解析出新技能/证据；猎奇：市场雷达新机会；社交：导师/分享反馈 |
| 投资 | 投入加载下一次触发 | 导入方案、记证据、编辑路线=投资；账本越用越值，下次触发更强 |
| 身份型习惯 | “我是…的人”比目标更持久 | 身份陈述：“我是有证据的 X 专业学生/求职者”；每条证据=一票；资本账本=身份证明 |
| Endowed progress | 给起点进度提高完成欲 | 首次导入即显示“已具备 N 项技能/M 条潜在证据”，而非从零 |
| IKEA effect | 自己做的更珍视 | 让用户确认/编辑课程→技能映射、自选路线，而非全自动 |
| 损失厌恶/沉没成本 | 怕失去已累积 | 账本累积、streak、阶段交接物；离开=重建十年资本 |
| SDT 胜任 | 感到有能力 | 成长进度环、证据打分、技能树点亮 |
| SDT 自主 | 感到有选择 | 可选多条路线、可编辑、可跳过 |
| SDT 归属 | 感到被连接 | AI 导师陪伴、同专业社区/榜样、分享 |
| 感知理解“你懂我” | 被理解→信任→依赖 | 用其真实培养方案/记忆个性化回应；主动提醒（考试周/招聘季）；记住上次目标 |

## 3. 护城河分层（对应商业研究）
1. 数据重力（SaaStr L2+）：账本资产累积互联，导出≠可用。
2. 工作流整合（Okta 式重映射成本）：阶段自动交接，单点工具无法复制整链。
3. 身份/情感（Atomic Habits + 感知理解）：用户把产品当“我的职业身份”一部分。
4. 习惯回路（Hooked）：内部触发+投资使回访成 reflex。

## 4. 可执行商业计划
### 4.1 北极星与指标
- 北极星：周活跃“资本增量”（每周新增证据/技能数），而非 DAU。
- 留存：D7/D30/D90 队列；habit index（周回访≥3 次占比）；阶段交接转化率（A→B→C）。
### 4.2 AARRR 心理设计
- Acquisition：校园侧仿 Handshake 接高校/career center（低 CAC）；职场侧靠资本账本口碑。
- Activation：首分钟 aha（解析出你的方案+endowed progress）。
- Retention：Hooked 回路+身份+损失厌恶（§2）。
- Referral：分享“我的四年地图/资本报告”=身份展示。
- Revenue：订阅=解锁更深陪跑（导师/雷达/报告），资本账本免费（锁定基础）。
### 4.3 留存实验计划（4–8 周）
- A/B：endowed progress vs 从零；身份陈述 onboarding vs 目标式；可变奖励频率。
- 衡量：D7/D30、habit index、投资率（记证据/编辑率）。
### 4.4 伦理护栏
- 频率上限、可关闭提醒、清晰退出与数据导出；优先 wellbeing 而非成瘾（Hooked 伦理+Octalysis 白帽）。

## 5. 与 v3 功能线的对齐
本文件机制全部挂载到 v3 三阶段工作台与资本 hub：A 阶段重 endowed progress/身份/感知理解；B 重内部触发/损失厌恶；C 重 investment/复利。资本 hub 是身份与数据重力的统一载体。
