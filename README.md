# 见微行远 EvidWay

**从真实轨迹，看清下一程。**

EvidWay 是证据型职业导航产品：把经历、职业信息与下一步小行动放在同一张决策地图上，帮助人更清楚地比较方向，再用行动获得反馈。

[产品概览](showcase/product-overview.md) · [用户流程](showcase/user-flow.md) · [核心功能](showcase/feature-map.md) · [演示案例](showcase/demo-case.md)

![EvidWay 产品展示主视觉](showcase/assets/hero-evidway-real.png)

## 展示内容

- 产品定位、目标体验与用户流程；
- 公开页面截图与脱敏样例画面；
- 一段目标体验演示视频；
- 商业计划与市场研究材料。

## 核心闭环

1. 整理经历，形成可确认的个人证据；
2. 比较多个职业方向，看到依据、差距与未知项；
3. 选择一个七天内可完成的小行动；
4. 记录行动结果，为下一次比较提供新信息。

产品介绍与目标体验见 [综合展示](showcase/README.md)。

## 展示边界

- 截图和视频中的个人信息均为脱敏样例；
- 展示材料不承诺就业、涨薪或转行结果；
- 研究材料中的市场、定价与收入数字是待验证假设，不是业绩承诺；
- 本仓只提供产品展示材料，不提供业务代码、数据集或用户资料。
