# 核心功能

## 证据型职业导航

### 个人证据账本

把经历中的事实、技能和成果整理为可以确认和追溯的证据条目。

**展示重点**：

- 证据内容；
- 证据来源；
- 用户确认状态；
- 需要补充的材料。

### 职业与技能地图

将中国职业条目、国际职业条目和技能关系连接起来，帮助用户看到职业之间的邻接关系，而不是只看到一个孤立岗位。

**展示重点**：

- 当前职业；
- 目标职业；
- 相邻职业；
- 技能连接；
- 数据来源和范围。

### 多路径比较

对同一个职业目标展示多条候选路径，避免把一个模型生成的答案当作唯一答案。

**展示重点**：

- 路径起点和终点；
- 需要补足的技能；
- 路径证据等级；
- 关键不确定性；
- 推荐的验证动作。

### 7 天验证行动

把宏大的职业问题转化为一项可以在短时间内完成并产生反馈的行动。

**展示重点**：

- 行动目标；
- 完成标准；
- 检查点；
- 用户反思；
- 结果回填。

## 数据可信度

产品展示中将使用 A / B / C / D / U 等证据等级，并明确标注数据不足。它们不是成功率，也不是模型置信度，而是对建议依据质量和完整性的说明。

## 隐私边界

- 不在展示素材中使用具体个人材料；
- 不在分析事件中记录简历全文；
- 截图只使用脱敏 fixture；
- 产品演示不会展示访问凭证、服务配置或用户资料。
